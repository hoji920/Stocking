# Stocking

개인용 주식 차트 도우미. 토스증권 Open API 시세로 국내·미국 종목 일봉을 보여주고,
지지/저항선, 초보자용 설명, 뉴스 요약을 함께 띄운다.

> 토스 시세는 본인 투자 목적으로만 이용 가능 → **127.0.0.1 로컬 전용. 배포 금지.**

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env   # 키 채우기
.\run.ps1                # http://127.0.0.1:8800
```

키가 없으면 데모 데이터(가짜 시세)로 화면만 뜬다.

| 키 | 용도 | 없으면 |
|---|---|---|
| `TOSS_CLIENT_ID/SECRET` | 시세·종목정보 | 데모 데이터 |
| `NAVER_CLIENT_ID/SECRET` | 국내 뉴스 | 국내 뉴스 없음 |
| `FINNHUB_API_KEY` | 미국 뉴스 | 미국 뉴스 없음 |
| `OPENAI_API_KEY` | 3줄 요약 + 호재/악재 태그 | 기사 목록만 |

토스 키 발급: 토스증권 WTS → 설정 → Open API. **허용 IP에 내 공인 IP를 등록**해야 한다 (안 하면 403).
토큰은 client 당 1개만 유효해서 `.token_cache.json`에 캐시해 재사용한다.

## 실시간 시세 · 봉 단위

- **실시간**: 토스 WebSocket(`wss://openapi-ws.tossinvest.com/ws/v1`) 체결을 서버가 연결 1개로 받아 브라우저에 SSE로 중계 (`backend/realtime.py`).
  지금 보는 종목 + 관심종목 + 보유종목을 구독. 현재가(깜빡임)·차트 마지막 봉·목록 가격이 체결마다 바뀐다.
  국내는 KRX+NXT, 미국은 프리·정규·애프터·데이마켓까지. 계정당 연결 2개 제한이라 보는 화면이 없으면 연결을 닫는다
- **봉 단위**: 1·3·5·15·30분, 1시간 / 일·주·월·년. 토스 API는 1분봉·일봉만 줘서 나머지는 서버가 묶는다 (`backend/bars.py`)
  - 분봉은 한국 시간 축. 토스 1분봉 시각은 실제로 '봉 끝 시각'이라 60초 당겨서 시작 시각으로 맞춤
  - 지지/저항·추세선·채널·보조지표는 보고 있는 봉 단위 기준. 매매 신호·뉴스 마커·비스듬히 그은 선은 일봉 전용
  - 첫 로딩: 1시간봉 3~4초, 월봉 2~5초, 년봉 4~12초 (이후 캐시)

## Render 배포 (나만 보기)

`render.yaml` 대로 올라감 (무료 플랜, 싱가포르). Render 대시보드 → New → Blueprint → 이 레포.

- **환경변수** (대시보드에서 입력, 레포엔 없음): `APP_PASSWORD`(필수), `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`, `FINNHUB_API_KEY`, `OPENAI_API_KEY`, `DEFAULT_WATCHLIST`(예: `MSTR,BE,INTC`)
- **접속**: `https://<서비스>.onrender.com` → 아이디 아무거나, 비밀번호 = `APP_PASSWORD`. 폰은 브라우저 메뉴 → 홈 화면에 추가
- **토스 허용 IP**: Render 서비스의 Outbound IP 들을 토스 WTS → Open API → 허용 IP 에 추가 (안 하면 403)
- **토큰 충돌 주의**: 토스는 client 당 토큰 1개만 유효 → Render 와 로컬을 **동시에 켜면 서로 토큰을 무효화**. 하나만 켤 것
- **무료 플랜 한계**: 15분 안 보면 잠듦(그동안 알림·실시간 X, 다시 열 때 ~1분), 재시작 때 관심종목·그은 선·알림 기록 초기화
  → 유료(starter)로 바꾸면 `render.yaml` 의 disk 주석 해제 + `DATA_DIR=/var/data`
- 로컬 실행은 그대로: `.\run.ps1` (이 PC에서만, 비밀번호 없음)

## 보유종목 · 검색

- 오른쪽 위 **보유종목 | 관심종목** 탭. 관심종목 탭엔 현재가·등락률·가장 가까운 지지/저항까지 거리 (1분마다 갱신)
- **내 보유종목**: 토스 계좌(종합매매)의 보유종목. 클릭하면 차트로 이동하고, 차트엔 `내 평단` 선이 표시됨. "전부 관심종목에"로 알림 대상에 한 번에 추가
- **검색**: 한글 이름·티커 자동완성 (토스 전체 종목 약 15,000개를 하루 1회 받아 메모리에서 검색)
- **여러 개 추가**: `엔비디아, MSFT, 브로드컴`처럼 쉼표로 붙여넣고 Enter → 관심종목에 추가
- 토스 앱의 '관심종목'은 Open API에 없어서 불러올 수 없다. 위 붙여넣기로 옮기면 된다.

## 자동으로 그은 선 (핵심 기능)

초보자가 어려워하는 '어디에 선을 긋지?'를 대신 해준다.

- **후보**: 수평 지지/저항 위아래 3개, 추세선 방향별 3개(서로 겹치는 선 제외), 채널 1개. 기본으로는 1등만 차트에
  (후보 순서는 닿은 횟수·유지 기간·최근에 닿았는지로 매기지만, 화면에 '신뢰도'로 보여주진 않는다 — 아래 검증 참고)
- **근거**: 오른쪽 목록이나 범례에서 선을 누르면 그 선이 실제로 닿은 지점에 점 + "3번 닿음 · 31봉에 걸쳐 · 마지막 12봉 전"
- **이 선 쓰기**: 자동 선을 내가 그은 선으로 저장 → 관심종목이면 닿을 때 알림
- **가독성**: 가격축 라벨은 현재가·가장 가까운 지지/저항·평단·고른 선만. 지표 이름/값은 차트 왼쪽 위 범례
- 채널은 꼬리 하나가 튀어도 따라가지 않음 (가장 먼 점이 두 번째보다 허용폭 넘게 멀면 무시)

## 자동 선 검증 (research/)

미국 30 + 국내 10 종목, 약 8년 일봉. 과거 각 시점에서 그 시점까지 데이터만으로 선을 긋고 이후를 본다 (미래 정보 없음).
대조군 = 같은 시점·기울기에 현재가와의 거리만 섞은 '근거 없는 선'.

| 질문 | 결과 |
|---|---|
| 선에 닿으면 튕기나? (`backtest_lines.py`) | 수평선은 대조군과 같음. 추세선은 오히려 2~4%p 덜 지켜짐. 판정 기준 4가지 모두 같은 결론 |
| 별점(닿은 횟수 등)이 높으면 더 잘 지켜지나? | 아니오 → 별점 표시 삭제 |
| 깨진 뒤 그 방향으로 이어지나? (`breakouts.py`) | 아니오. 5·10·20봉 뒤 수익률이 '아무 날 진입'과 비슷 (시장 자체 흐름 수준) |
| 매물대·라운드넘버·전고점·이평선·피벗·피보나치는? (`methods.py`) | 보정 후 유의하게 나은 방식 없음. 이평선 지지 단서는 새 종목 확증(`confirm.py`)에서 재현 안 됨 |
| 확증된 것 | **자동 추세선 지지는 무작위 위치 선보다 3.6~4%p 더 잘 깨짐** (새 40종목에서도 재현, p=0.0015) |
| 주봉으로 그으면 나아지나? (`weekly.py`) | 아니오. 주봉 선도 대조군과 같거나(수평선) 낮음(추세선). 채널 바닥 +12%p 하나는 표본 188개·60봉 기준에선 사라짐 → 우연으로 봄 |

→ 자동 선은 **예측 도구가 아니라 차트 읽기 도구**로 쓴다. 결과 표: `research/results/*.md`
주의: 지금 살아남은 대형주(생존 편향), 같은 날 여러 종목이 함께 움직여 p값이 실제보다 작게 나올 수 있음.

```powershell
python -m research.backtest_lines   # 선 긋기 + 대조군 (약 15초, 첫 실행은 시세 수집 40초)
python -m research.sensitivity      # 판정 기준 바꿔보기
python -m research.breakouts        # 깨진 뒤 이어졌나
python -m research.weekly           # 주봉으로 그은 선 vs 일봉으로 그은 선 (약 1분)
python -m research.methods          # 13가지 방식 비교 (약 2분)
python -m research.confirm          # 확증: 탐색에 안 쓴 미국 40종목
```
전체 정리: `research/REPORT.md`

## 추세선 · 채널 · 지표

차트에 뭘 그릴지는 전부 **+ 추가** 메뉴에서 고른다. 켜진 것만 칩으로 보이고 ×로 뺀다 (브라우저에 기억).
기본: 지지/저항선(위아래 2개) · 내 평단 · 내가 그은 선 · 거래량.

- **자동 추세선**: 스윙 저점끼리(지지)·고점끼리(저항) 이은 선 중, 이후 종가가 뚫지 않고 가장 많이 닿은 선 1개씩
- **추세 채널**: 닿은 횟수 많은 추세선을 기준으로, 반대편 최고가/최저가를 지나는 평행선. 채널 안 위치(0%=바닥, 100%=천장)를 설명 카드로 보여주고, 평행선도 알림 대상
- **직접 긋기**: ✏️ 추세선(두 점 클릭, 오늘까지 연장) / ― 수평선(한 번 클릭). `data/drawings.json`에 저장, 알림 대상에도 포함
- **+ 지표**: SMA, EMA, 볼린저밴드(차트 위) / RSI, MACD, 스토캐스틱, ATR, OBV(아래 칸). 칩에서 기간 수정·삭제, 선택은 브라우저에 기억
  - 새 지표 추가: `frontend/indicators.js`의 `INDICATORS`에 `calc` 하나 추가

## 차트 패턴 (종목 탭 '차트 패턴', `backend/patterns.py`)

- 이중 바닥(W) · 역헤드앤숄더 · 상승 삼각수렴 · 상승 깃발형 · 컵앤핸들을 일봉에서 찾아 노란 선으로 그림 (형성 중 / 최근 돌파)
- 돌파일 거래량이 20일 평균 1.5배 이상이면 '거래량 동반'
- 과거 돌파는 매매 신호로도 (차트 마커·과거 성적·알림 설정 가능, 기본 알림은 꺼짐)
- 패턴마다 **검증 숫자**를 같이 보여줌: 80종목·8년에서 돌파 후 20봉 초과수익이 5종 모두 0 근처(아무 날과 차이 없음) → `research/results/patterns.md`

  원자재(WTI·브렌트·금·구리·천연가스), 환율·코인(달러인덱스·원/달러·BTC·ETH), 국내(코스피·코스닥). 1분마다 갱신, 몇 분 지연

## 급등락 알림 + "왜 움직였지?"

- 관심종목이 전일 종가 대비 `ALERT_MOVE_PCT`(기본 3%) 단계를 새로 넘으면(3 → 6 → 9%) 알림 1번
- 이유: 그 종목 최근 3일 뉴스(미국 Finnhub, 국내 네이버) + 시장 전체 움직임(SPY / KODEX200)을 LLM 에 주고
  **주어진 기사 안에서만** 원인을 1~2문장으로. 근거가 없으면 "찾지 못했어요". 근거 기사 링크 같이 표시
- 같은 단계는 하루 한 번, 재시작해도 다시 안 보내고 LLM 도 다시 안 부름
- 종목 화면 제목 옆 **왜 움직였지?** 버튼으로 언제든 수동 확인 (`/api/why/{symbol}`, 5분 캐시)
- **ETF 기초자산**: 토스 영문 이름·레버리지 배수로 기초자산을 알아내서(BITX→비트코인 2배, SOXL→반도체 3배, TSLL→TSLA 2배,
  TLT→미국 10년 금리, SQQQ→나스닥 인버스) 기초자산 등락·뉴스·관련 종목 뉴스까지 보고 이유를 찾음 (`backend/underlying.py`)

## 지지/저항 알림

화면 위쪽 칩 = 관심종목. 차트 제목 옆 ☆ 로 추가/삭제. 관심종목만 감시한다.

- 서버가 `ALERT_POLL_SEC`(기본 60초)마다 토스 현재가를 한 번에 조회
- **근접**: 선까지 `ALERT_NEAR_PCT`%(기본 1%) 이내 / **돌파·이탈·회복**: 직전 조회가와 현재가 사이에 선을 건넘
- 같은 종목·같은 선·같은 종류는 하루 한 번만. 기록은 `data/alerts.json`
- 전달: 화면 토스트 + 브라우저 알림(탭이 백그라운드일 때) + 텔레그램(`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 넣으면)
- 서버가 꺼져 있으면 감시도 멈춘다
